# CodexとObsidianで始める業務のLLM Wiki

会議の記録、業務手順、判断の理由を Markdown で残し、関連するノート同士をつなげて後から使えるようにする、自分用の LLM Wiki です。Obsidian で記録を読み書きし、Codex に資料の整理、リンクの追加、根拠付きの回答を依頼できます。

## 始め方

1. ZIPを展開し、4つの Markdown ファイルがあるフォルダーを、Obsidian で保管庫として開きます。
2. [HANDOFF.md](HANDOFF.md) に沿って、フォルダーと自分用のメモを作ります。
3. Codex に架空の会議メモ1件を整理させ、決定事項から関連手順と元の資料をたどります。

使うアプリは Codex と Obsidian です。[AGENTS.md](AGENTS.md) に Codex が参照・編集できる範囲と、整理時のルールを置いています。

## 同梱ファイル

| ファイル | 用途 |
|---|---|
| [README.md](README.md) | この保管庫の使い方と入口 |
| [HANDOFF.md](HANDOFF.md) | 初期設定と最初の動作確認 |
| [SPEC.md](SPEC.md) | フォルダー構成、記録ルール、コピーして使える架空例 |
| [AGENTS.md](AGENTS.md) | Codexが読む範囲、編集権限、整理時のルール |

業務の記録を入れる前に、組織で認められた保存先と、Codexで扱ってよい情報の範囲を確認してください。初回は架空データで試せます。
